DeckControl

Ferramenta web para gerenciar cartas durante sessões de RPG.

Projeto criado para uso em uma campanha de Ordem Paranormal
utilizando a trilha de ocultista baseada em 
cartas do suplemento **Expandindo a Fenda**.

Funcionalidades

* Seleção de cartas com clique
* Múltiplas cartas ativas ao mesmo tempo
* Painel automático de descrições
* Busca por valor ou naipe
* Salvamento automático com LocalStorage
* Interface responsiva para celular
* Deploy com GitHub Pages

Tecnologias usadas
* HTML
* CSS
* JavaScript
* LocalStorage
* GitHub Pages

Objetivo

Criar uma ferramenta simples para agilizar o uso das cartas
durante sessões de RPG, evitando consultas demoradas
no livro.
